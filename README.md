# Calculadora de Matrizes em C#

Projeto desenvolvido em C# para realizar operações matemáticas com matrizes por meio do terminal.

## Funcionalidades

- **Soma e subtração:** operações entre matrizes de mesmas dimensões.
- **Multiplicação:** multiplicação de matrizes com verificação de compatibilidade das dimensões.
- **Transposta:** troca das linhas pelas colunas de uma matriz.
- **Determinante:** cálculo do determinante de uma matriz quadrada.
- **Matriz inversa:** cálculo da inversa, com verificação de existência.

## Tecnologias utilizadas

- C#
- .NET 8.0
- MathNet.Numerics 5.0.0

## Características

- Validação das entradas numéricas.
- Verificação das dimensões necessárias para as operações.
- Exibição dos resultados com até duas casas decimais.
- Possibilidade de realizar várias operações na mesma execução.

## Como executar

1. Clone este repositório.
2. Abra o arquivo `Matrizes_Calculadora.csproj` em um ambiente compatível com .NET 8.0.
3. Restaure as dependências do projeto.
4. Execute a aplicação.
